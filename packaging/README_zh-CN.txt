FTP绿色版服务端 v0.7.1

一、软件简介

FTP绿色版服务端是一款适用于 Windows x64 的免安装 FTP 服务端。
程序解压后即可运行，主要用于在局域网内共享本机文件夹。

本版本只保留本地磁盘 FTP 功能，不包含云存储、SFTP、邮件、Webhook
和第三方认证后端，因此体积更小，也更适合普通用户使用。


二、运行环境

- 操作系统：Windows 10、Windows 11 或相应 Windows Server x64 版本
- 安装方式：绿色免安装
- 管理员权限：正常运行不需要；修改 Windows 防火墙时可能需要
- 网络要求：局域网使用不需要连接互联网


三、首次使用

1. 将压缩包完整解压到一个固定目录，不要直接在压缩包内运行。
2. 双击 FTPServerGUI.exe。
3. 确认“监听IP”显示的是需要提供 FTP 服务的本机网卡地址。
4. 保持默认 FTP 端口 12121，或根据需要修改。
5. 点击“新增账户”。
6. 填写账户名称和密码，也可以点击“随机生成”。
7. 点击“选择目录...”，选择该账户可以访问的文件夹。
8. 根据需要勾选“只允许下载（只读）”。
9. 点击“保存账户”。每个账户都必须单独保存。
10. 点击主窗口底部的“保存设置”。
11. 点击“启动服务”。
12. 界面显示“服务运行中”和连接地址后，即可使用 FTP 客户端连接。


四、FTP 客户端连接方法

在 FileZilla、WinSCP、资源管理器或其他 FTP 客户端中填写：

- 协议：FTP
- 主机：服务端界面“连接地址”中显示的 IP 地址
- 端口：默认 12121
- 用户名：在“FTP账户与访问目录”中创建的账户名称
- 密码：创建账户时填写或随机生成的密码

示例：连接地址显示为 ftp://192.168.1.20:12121 时，主机填写
192.168.1.20，端口填写 12121，用户名和密码填写服务端中保存的账户信息。

客户端和服务端应处于能够互相访问的网络中。局域网内通常需要连接到
同一个路由器或同一内部网络。


五、服务器设置参数

1. 监听IP

决定 FTP 服务绑定到哪一个本机网络地址。

- 默认值：系统默认主网卡的 IPv4 地址
- 物理网卡地址：适合局域网内其他电脑访问
- 127.0.0.1：仅允许本机访问，其他电脑无法连接
- 0.0.0.0：监听所有网卡地址

电脑更换网络后，IP 地址可能发生变化。如果客户端无法连接，请重新检查
当前监听IP。修改监听IP后，需要停止并重新启动 FTP 服务。

2. FTP端口

FTP 控制连接使用的端口。

- 默认值：12121
- 有效范围：1-65535
- 不能与其他程序占用的端口相同
- 不能位于本软件设置的被动端口范围内

客户端连接时必须填写相同端口。

3. 最大连接

允许同时连接到服务器的客户端数量。

- 默认值：10
- 设置为 10 表示最多同时接受 10 个连接
- 设置为 0 表示不限制最大连接数

普通家庭或办公室局域网建议保持默认值，避免异常客户端占用过多连接。

4. 被动端口

FTP 被动模式传输文件和目录列表时使用的数据端口范围。

- 默认范围：2122-2130
- 起始端口不能大于结束端口
- FTP 控制端口不能包含在此范围内

大多数 FTP 客户端默认使用被动模式。防火墙除了允许 FTP 控制端口外，
还必须允许整个被动端口范围，否则可能出现“能够登录但无法显示目录”或
“能够登录但无法传输文件”的情况。

5. 空闲超时

客户端长时间没有操作时，服务器断开连接前等待的分钟数。

- 默认值：15 分钟
- 设置为 0 表示不启用空闲超时


六、账户和访问目录参数

1. 账户列表

显示当前已经添加的 FTP 账户。点击账户名称可查看和修改该账户设置。

2. 账户名称

FTP 客户端登录时使用的用户名。不同账户不能使用相同名称。

3. 账户密码

FTP 客户端登录时使用的密码。

- 新增账户时必须填写密码
- 修改已有账户时，密码框留空表示保持原密码不变
- 已保存的哈希密码无法还原显示；忘记密码时请重新设置
- 不建议使用简单密码或与其他网站相同的密码

4. 随机生成

生成一个 16 位安全随机密码。密码由大小写字母、数字和部分符号组成，
并避开容易混淆的字符。生成后密码会自动显示并被选中。

5. 显示密码

勾选后显示密码框中的内容，取消勾选后以掩码显示。

6. 复制密码

将当前密码复制到 Windows 剪贴板，以便提供给 FTP 用户或粘贴到客户端。
程序日志不会记录密码内容。复制完成后请注意清理剪贴板和聊天记录中的密码。

7. 访问目录

该账户登录后能够访问的本机文件夹。客户端看到的 FTP 根目录就是此目录。

- 每个账户可以选择不同目录
- 目录必须真实存在
- 不要把系统目录或包含隐私文件的目录共享给不可信用户

8. 只允许下载（只读）

勾选后，账户只能查看目录和下载文件，不能上传、删除、重命名文件或创建目录。
不勾选时，账户可以在 Windows 文件权限允许的范围内进行写入操作。

9. 保存账户

保存当前账户编辑内容。只修改输入框而不点击“保存账户”，账户更改不会加入
最终配置。保存账户后还应点击主窗口底部的“保存设置”。

10. 删除

删除账户列表中当前选中的账户。删除后点击“保存设置”才会写入配置文件。


七、高级设置参数

1. 公网IPv4

服务器位于路由器后方并需要通过公网访问时，可填写客户端能够访问的公网 IPv4。
服务器会在 FTP 被动模式中向客户端公布这个地址。

- 仅在局域网内使用时请留空
- 公网 IP 发生变化后需要及时修改
- 公网使用还需要在路由器上转发 FTP 端口和全部被动端口

2. 连接安全模式

- 普通FTP或FTPS：允许普通 FTP；配置有效证书后也可接受显式 FTPS
- 强制显式FTPS：客户端先连接 FTP 端口，再升级为 TLS 加密连接
- 隐式FTPS：客户端建立连接时立即使用 TLS 加密

强制显式 FTPS 或隐式 FTPS 必须同时配置 TLS 证书和 TLS 私钥。
客户端所选协议和加密方式必须与服务端一致。

3. TLS证书

服务端证书文件，使用 PEM 格式。用于 FTPS 身份验证和传输加密。

4. TLS私钥

与 TLS 证书配套的私钥文件，使用 PEM 格式。请妥善保管，不要发送给他人。

5. 日志文件

运行日志保存位置。默认值为 logs\ftpserver.log，路径相对于程序所在目录。

6. 记录FTP命令

记录客户端与服务端之间的 FTP 命令交互，适合排查登录和传输问题。
启用后日志增长速度会加快。

7. 记录文件操作

记录上传、下载、删除等文件访问行为。启用后日志增长速度会加快。

8. 哈希保存密码

将配置文件中的明文密码转换为 bcrypt 哈希后保存。建议启用。

启用后无法从配置文件恢复原密码，因此应在生成或修改密码时先复制并妥善保存。
如果用户忘记密码，只能重新设置新密码。

9. 启用文件HASH

允许支持该功能的 FTP 客户端通过 HASH 命令计算文件校验值，用于检查文件完整性。


八、按钮和运行行为

- 启动服务：保存并检查设置，然后开始监听 FTP 端口
- 停止服务：停止接受新连接并关闭当前 FTP 服务
- 保存设置：将服务器和账户设置写入 ftpserver.json
- 开机启动：当前 Windows 用户登录后自动运行本程序，无需管理员权限
- 关于：显示软件名称、版本、版权和开源许可信息
- 退出：停止 FTP 服务并完全退出程序

点击窗口右上角关闭按钮不会退出程序，而是隐藏到系统托盘。需要重新打开窗口时，
单击托盘图标；需要完全结束程序时，请点击主窗口或托盘菜单中的“退出”。

如果启用开机启动后移动了程序目录，请先关闭“开机启动”，移动完成后重新勾选，
以便更新注册表中保存的 EXE 路径。


九、Windows 防火墙设置

本程序不会自动修改 Windows 防火墙。

其他电脑需要连接时，应在 Windows 防火墙中允许以下 TCP 入站端口：

- FTP 控制端口：默认 12121
- 被动传输端口：默认 2122-2130

建议只对“专用网络”开放。如果修改了软件中的端口，防火墙规则也要同步修改。


十、配置文件和绿色版说明

- ftpserver.json：服务器、账户和目录配置
- logs\ftpserver.log：默认日志文件
- data：预留数据目录
- LICENSE.txt：开源许可证
- 使用说明.txt：本说明文件

备份软件时可以复制整个文件夹。不要在 FTP 服务运行期间直接删除程序目录。
配置文件可能包含账户信息，复制或发送前请检查是否已经启用哈希保存密码。


十一、常见问题

1. 客户端提示连接被拒绝

确认服务状态为“服务运行中”，客户端 IP 和端口填写正确，并检查 FTP 控制端口
是否被防火墙拦截或被其他程序占用。

2. 可以登录，但无法显示目录或传输文件

通常是被动端口没有全部放行。请检查 Windows 防火墙、路由器端口转发以及客户端
是否使用被动模式。

3. 同一台电脑可以连接，其他电脑不能连接

确认监听IP不是 127.0.0.1，并检查防火墙是否允许专用网络访问。客户端应使用服务端
的局域网 IPv4 地址，而不是 127.0.0.1。

4. 修改设置后没有生效

先点击“保存账户”和“保存设置”，然后停止并重新启动 FTP 服务。

5. 随机密码保存后看不到

这是正常的安全行为。请在生成密码时点击“复制密码”并保存。已经哈希的密码不能
还原；如已丢失，请为该账户重新设置密码。

6. 开机启动没有生效

确认复选框仍为勾选状态，且程序没有被移动或删除。移动程序后应重新设置开机启动。
部分安全软件可能会阻止启动项，需要在安全软件中允许本程序。


十二、安全提示

- 普通 FTP 不加密用户名、密码和传输内容，建议只在可信局域网中使用
- 需要通过互联网使用时，建议配置 FTPS、强密码和严格的防火墙规则
- 不要共享 Windows 系统目录、个人隐私目录或整个磁盘根目录
- 定期检查账户、共享目录和日志，删除不再使用的账户
- 公网部署涉及路由器、防火墙和证书配置，不建议不了解网络安全的用户直接开放
